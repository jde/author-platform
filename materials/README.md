# Materials

Shared assets every pitch and post draws from. All are DRAFTS in Helen's voice, built only from facts in
`research/`. Square brackets mark what only Helen can fill. Nothing here goes out until she has edited it.

| File | Use |
|---|---|
| `bios.md` | 25, 60, 120 and 250 word bios, plus speaker and VR bios |
| `books.md` | One-line, one-paragraph and back-cover descriptions, buy links, praise |
| `talk-topics.md` | Twelve talk and podcast topics with a two-sentence pitch each |
| `one-sheets.md` | Podcast one-sheet, event one-sheet, café one-sheet, press kit checklist |
| `pitch-skeletons.md` | The four reusable email shapes (podcast, event, press, award cover letter) |
| `voice.md` | How Helen writes online, from her own posts; the rules every draft is checked against |
